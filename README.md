Viewer for the icons inside the Blender project.

See https://www.blender.org/about/license/ for license information.

## Development setup

```sh
git clone https://projects.blender.org/blender/blender.git
cd blender
git clone https://github.com/bfanger/blender-icon-viewer.git icon-viewer
cd icon-viewer
pnpm install
pnpm run icons
pnpm run dev --open
```
